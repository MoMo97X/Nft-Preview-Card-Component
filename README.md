### What I learned

#### Using @layer css in design

- In this project i learned to use the @layer css cascade rule's and how it's specificity work.

- @layer structure i used :

```css
@layer reset,font,base;

@layer reset {
  /* code */
}

@layer font {
  /* font */
}

@layer base {
  /* code */
}
```
